# Object-Oriented Programming (OOP) Demonstration in C#

## 📘 Overview

This project is designed to help learners understand the core principles of Object-Oriented Programming (OOP) using C#. It includes well-documented examples that demonstrate:

- ✅ Classes and Objects
- ✅ Encapsulation
- ✅ Inheritance

Each concept is explained with comments and practical code snippets to reinforce learning.

---

## 📦 Project Structure

### 1. `Person` Class – Classes and Objects
- Defines a `Person` class with properties: `Name`, `Surname`, and `Age`.
- Includes a method `Introduce()` to demonstrate encapsulation.
- Shows how to create and use an object instance.

### 2. `Animal` and `Dog` Classes – Inheritance
- `Animal` is a base class with properties and methods.
- `Dog` inherits from `Animal` and overrides the `Speak()` method.
- Demonstrates code reuse and polymorphism.

### 3. `BankAccount` Class – Encapsulation
- Uses a private field `balance` to protect internal state.
- Provides public methods `Deposit()` and `GetBalance()` for controlled access.
- Demonstrates validation and safe interaction with object data.

---

## 🚀 How to Run

1. Open the project in Visual Studio or any C# IDE.
2. Run the `Main()` method or individual demonstration methods:
   - `DemonstrateEncapsulation()`
   - `DemonstrateInheritance()`
   - `DemonstrateClassesAndObjects()`
